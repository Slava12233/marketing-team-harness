# experiments/

One note per Meta experiment, made from `memory/templates/experiment.md`. The pre-registration (hypothesis, the one variable, the primary metric and window, the decision rule, the minimum events) is frozen on the day the test starts; the verdict is written once, dated, with `as_of` and `source`. The running list of tests is also kept in `plans/experiments-log.md`.
