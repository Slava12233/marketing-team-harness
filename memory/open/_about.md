# open/

One note per open item, made from `memory/templates/open.md`, with `owner:` set to `owner`, `operator`, `harness`, `product-team` or `lawyer` and `status: open` until it is done (then `status: done`). The HOT, HOME's generated block, the open-items base and the control room's task list read these notes by owner, so the summary says in one line what is waiting and who acts.
