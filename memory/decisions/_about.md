# decisions/

One note per ruling by the Owner (`YYYY-MM-DD-slug.md`), made from `memory/templates/decision.md`: the ruling in the Owner's words where possible, the context, what it replaces, what it applies to. A decision is never edited after its day; a change is a new note with `supersedes:` set, and the old one gets only `status: superseded` and `superseded_by:`. A go to spend is not a decision note: it is valid only in the chat message that contains it.
