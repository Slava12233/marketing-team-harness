# An empty paused ad set is a safe audience-sizing sandbox

**The fact.** The "Estimated audience size" card updates per edit, so an empty paused ad set is a safe sizing sandbox; the sizes shown beside search suggestions are worldwide, not for the targeted country.

**Evidence.** Observed on a single company's ad account on 2026-10-21; ported to this template on 2026-10-26.

**How to apply.** Size audiences on an empty paused set, read the card (not the suggestion figures), then discard that object's draft ([[2026-10-21-editor-edits-autosave-as-drafts]]). Figures carry `as_of`.
