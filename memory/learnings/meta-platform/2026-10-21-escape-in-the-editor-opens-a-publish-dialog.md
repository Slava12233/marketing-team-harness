# Escape in the Ads Manager editor opens "Publish draft items?"

**The fact.** Escape in the editor opens a "Publish draft items?" dialog (click Close, never Publish).

**Evidence.** Observed on a single company's ad account on 2026-10-21; ported to this template on 2026-10-26.

**How to apply.** Leave the editor by mouse; if the dialog appears, Close.
