# There is no targeting-search tool in the MCP

**The fact.** There is no targeting-search tool. Look interest, job-title and behaviour names and sizes up in the Ads Manager ad set editor (detailed targeting search box), add one to a draft through the UI, read the draft back with the MCP to get the ids. Targeting ids can also come from the account's own earlier ad sets.

**Evidence.** Observed on a single company's ad account on 2026-10-12; ported to this template on 2026-10-26.

**How to apply.** Plan targeting lookups as an Ads Manager step (in the Owner's browser, only when the Owner asks for it), or reuse ids from earlier ad sets.
