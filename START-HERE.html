מדריך מהיר: צוות השיווק

הכלי מנתח, מתכנן, כותב ובונה קמפיינים ב-Meta (פייסבוק, אינסטגרם, וואטסאפ) ובגוגל. הכול נבנה מושהה (PAUSED). שום דבר לא עולה לאוויר ושום שקל לא יוצא בלי אישור של הבעלים באותה הודעה.

אני עובד עם: ב-Codex כל פקודה מתחילה ב-$ במקום /

1. התקנה אצל הלקוח (פעם אחת)

  1. תיקייה חדשה לעסק. מורידים את הריפו לתיקייה ריקה: 
    git clone <repo-url> <client-name>
    במקום <repo-url> שמים את כתובת הריפו, ובמקום <client-name> את שם התיקייה של הלקוח. אפשר גם להוריד את ה-ZIP ולפרוס אותו. תיקייה אחת לכל עסק. עותק של תיקייה של לקוח אחר מתאפס לבד: הקבצים הקודמים עוברים ל-.previous-company/, ושום דבר לא נמחק.
  2. Bootstrap. מתקין את כל מה שחסר בלי שאלות (Git, Node.js, Claude Code, Chrome, Obsidian ועוד) ופותח את אשף ההתקדמות dashboard/setup.html. מריצים בתוך התיקייה: 
    powershell -ExecutionPolicy Bypass -File .\bootstrap.ps1 -Yes
    ב-Mac: 
    bash bootstrap.sh --yes
  3. פותחים את התיקייה ב-Claude. אפליקציית Claude, לשונית Code, Open folder, Trust, ומאשרים את שני השרתים meta-ads ו-fal.
  4. פותחים את התיקייה ב-Codex. את התיקייה עצמה, לא תיקייה מעליה. אפשר באפליקציית Codex, או codex בטרמינל בתוך התיקייה. אחר כך:
    א. Trust project.
    ב. /hooks, ומאשרים את שלושת ה-hooks. בלי זה שומר החשבון כבוי.
    ג. בטרמינל: 
    codex mcp login meta-ads
    codex mcp login fal
    ד. פותחים סשן חדש.
    להתקנת Codex: npm install -g @openai/codex
  5. תוסף כרום. באפליקציית Claude: Settings, Connectors, Claude in Chrome.באפליקציית Codex: Plugins, Chrome. הבעלים צריך להיות מחובר בכרום שלו לפייסבוק ולגוגל.
  6. מקלידים /connect. הכלי מחבר הכול, צעד אחר צעד, ונגמר בבדיקה ירוקה.
  7. מקלידים /campaign. ראיון, מחקר, תוכנית ובניית הקמפיין הראשון, מושהה.

5. כללי ברזל

  • הפעלה, העלאת תקציב והארכה רק עם go של הבעלים באותה הודעה. קודם הכלי מציג כמה זה עולה ליום, את התקרה ואת תאריך הסיום. אחר כך הבעלים כותב, למשל: מאשר: להפעיל את <הקמפיין>, <סכום> ליום, תקרה <סכום>. הניסוח המדויק נקבע ב-config/operator.md.
  • הכול נבנה מושהה. קריאה ועצירה מותרות תמיד.
  • חשבון מודעות אחד לכל תיקייה. ניסיון לגעת בחשבון אחר נחסם לפני שהוא נשלח.
  • סודות לעולם לא בצ'אט. הטוקן עובר מכפתור ההעתקה של Meta לקובץ .env בלי שאף אחד רואה אותו. סוד שהודבק בצ'אט נחשב שרוף, וצריך להחליף אותו.
  • כל עותק הוא עסק חדש. לוגינים שכבר קיימים במחשב נבדקים מחדש לעסק הזה.
  • ב-Codex: לפני הפעלה הכלי כותב לעצמו "כרטיס go" עם המילים של הבעלים, ובלעדיו השומר חוסם. זה קורה אוטומטית, והסוכנים לעולם לא כותבים כרטיס כזה.
