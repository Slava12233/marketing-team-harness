# Changelog

All notable changes to the Marketing Team Harness are recorded in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). A release is an annotated tag `vX.Y.Z` plus the zip that `release.sh` / `release.ps1` builds from it; the release scripts refuse to tag a version that has no `## [X.Y.Z]` heading here.

## [Unreleased]

The product build of 2026-10-26: what a buyer needs to go from a computer without the tools to a configured harness and a first campaign built PAUSED. Extended on 2026-10-28 with the onboarding in buyer mode: the keys pass in the Owner's own Chrome, the desktop app as the baseline, and a first flight of two ads. Extended on 2026-10-29 with the onboarding in two parts (`/connect`, `/campaign`), the Owner's language ruling every question, the token moved from the clipboard into `.env` by a tool, and a sturdier bootstrap.

### Fixed

- **A copy of the harness skipped Part 1.** The template repository carried a company's filled `config/`, vault, `checklist.md`, plans and the flight's creatives, so a fresh clone (or a folder copied from a company's harness) looked connected, and `/setup` sent the new Owner straight to `/campaign`. Every copy is now a new business, and the template is blank again: its company files are exactly the blank files of `templates/company/`; the previous company's files left this repository (git history still holds them).
- `dashboard/setup-page.test.mjs` copied the repository's own `config/`, `checklist.md` and `dashboard/state.json` as its "bare template", so four of its six tests failed as soon as a company had run the wizard in that copy. The bare-template fixture is now `templates/company/` (the placeholder `config/`, the empty checklist and state file: the same blank files a new copy is reset to; listed under `[replace]` in `docs/UPGRADE-PATHS.txt`), and the tracked-item count follows the new `flight.research` item (52 tracked with the two optional rows hidden).
