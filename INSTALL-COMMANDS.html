פקודות למתקין

התקנת צוות השיווק על מחשב חדש של לקוח: מה מקלידים, איפה, ובאיזה סדר. כל פקודה אומרת בסופה מה הפקודה הבאה.

  • שום דבר לא מופעל ולא מוציא כסף. הקמפיין הראשון נבנה במצב PAUSED. רק הודעת go של בעל העסק, עם הסכום, מפעילה מודעה.
  • טוקן, סיסמה או קוד לא נכנסים לצ'אט. את הטוקן מעתיקים בכפתור Copy של Meta, וכלי מעביר אותו לקובץ .env בלי שאיש רואה אותו.
  • הכניסה ל-Meta היא בפרופיל של בעל העסק, לא של המתקין. גם כרטיס האשראי, הקודים ותנאי השימוש הם שלו.

המסלול, לפי הסדר

"טרמינל" הוא חלון PowerShell שנפתח בתיקיית ההרנס (קליק ימני על התיקייה ← Open in Terminal). "Claude" הוא תיבת ההודעה של Claude Code.

0.4 Claude שתי שאלות אחרי השפה, בכל סשן עד ש-/check אומר READY ההרנס בודק בעצמו אם תוסף Claude לכרום מחובר, ושואל רק אם לא מצא. אחר כך שואל אם הסשן במצב Bypass permissions, ומציג את הלחיצות אם מבקשים. תוסף: במסלול הזה עונים "ממשיכים בלי". Bypass: Settings ← Claude Code ← מדליקים Allow bypass permissions mode, ואז בבורר המצב שמתחת לתיבת ההודעה (Ctrl+Shift+M) בוחרים Bypass permissions. אפשר גם להישאר עם אישורים, ההרנס ממשיך בכל מקרה.
שלב 1: הכלים
1 Claude
/install
 דוח של מה קיים ומה חסר, ואז התקנה של כל החסר: Node.js, אפליקציית הדסקטופ של Claude, Chrome, Obsidian, FFmpeg, תוסף הווידאו וקובץ .env ריק. מאשרים הרשאות של Windows. בסוף פותחים סשן חדש, עדיף בלשונית Code של אפליקציית הדסקטופ.
שלב 2: החיבור ל-Meta
2.1 Claude
/meta
 סבב שאלות קצר (שם העסק, שם קצר, שפת בעל העסק), ואז הכניסה ל-Meta: /mcp ← meta-ads ← log in. בעל העסק מתחבר בפרופיל שלו ומשתף רק את התיק העסקי, חשבון המודעות והעמוד של העסק הזה. אחר כך סשן חדש.
2.2 Claude
/meta
 ממשיך מהמקום שנעצר: בחירת חשבון המודעות והעמוד, אפליקציית המפתחים, ה-System User והטוקן. אחרי כל צעד בדיקה חיה. לוחצים במסכי Meta לפי רשימת הקליקים וכותבים done. בטוקן: לוחצים Copy וכותבים copied.
שלב 2ב: fal, תמונות ווידאו ב-AI (לא חובה)
2ב Claude
/fal
 מוביל את חיבור חשבון fal. אחרי הכניסה, בסשן חדש, קורא את שם החשבון ואת היתרה. שום דבר לא נוצר ולא מחויב. בלי fal הכול עובד, רק בלי תמונות ווידאו שנוצרים ב-AI. נרשמים ב-fal.ai בחשבון של הלקוח (אימייל, סיסמה וכרטיס מקלידים רק במסך של fal), ואז /mcp ← fal ← log in, סשן חדש, ושוב /fal. הלקוח לא רוצה: /fal skip.
שלב 3: בדיקה
3 Claude
/check
 טבלת ירוק/צהוב/אדום ופסק דין אחד: READY, או NOT READY עם הפקודה שמתקנת כל שורה אדומה. אם NOT READY: מריצים את הפקודה שנכתבה ליד השורה, ואז שוב /check.
שלב 4: העסק והקמפיין הראשון
4 Claude
/campaign
 איזה קמפיין בונים, סבבי שאלות על העסק, מחקר שוק, תוכנית, קופי, קריאייטיב, והקמפיין נבנה PAUSED ומוצג כתצוגה מקדימה של Meta. בעל העסק עונה על השאלות ובוחר. אם סוג הקמפיין צריך עוד פריט ב-Meta, Claude אומר איזו פקודה להריץ.
סיום
5 Claude
/sync
 סוגר את הסשן: הזיכרון מתעדכן והרשימה לבעל העסק נכתבת. עוברים על "לפני שעוזבים" בסוף הדף.

ב-macOS שלב 0 הוא שורה אחת, curl -fsSL https://claude.ai/install.sh | bash, ואחריה claude. Python לא נדרש.

צעד בודד ב-Meta

/meta מריץ את ארבעת הצעדים האלה לפי הסדר. אפשר להריץ כל אחד לבד, למשל אחרי תקלה.

מה מקלידיםמה המתקין עושהמה Claude בודק
/meta login
 /mcp ← meta-ads ← log in, בפרופיל של בעל העסק. אחר כך סשן חדש. חשבון המודעות של הלקוח מופיע בקריאה חיה.
/meta assets
 בוחר את חשבון המודעות ואת העמוד מתוך הרשימה, ומאשר שיש אמצעי תשלום וטלפון מאומת. המזהים, המטבע והתקציב היומי המינימלי נקראים ונרשמים.
/meta app
 יוצר אפליקציית מפתחים (Marketing API) ו-System User בתפקיד Employee, ומשייך לו שלושה נכסים: חשבון המודעות, האפליקציה והעמוד. נבדק בצעד הטוקן.
/meta token
 Generate token, שש ההרשאות, Generate, Copy, סוגר את החלון וכותב copied. הטוקן עובר ל-.env, ושלוש בדיקות רצות: העלאות, הרשאות, טפסי לידים.
/meta status
 כלום. מציג מה נעשה, מה פתוח ומה הפקודה הבאה.

כשמשהו נכשל

מה רואיםמה זהמה עושים
הכלים של Meta חסרים אחרי הכניסה הם נטענים רק בסשן שנפתח אחרי הכניסה. סשן חדש, ואז /meta
קוד 10 בבדיקת טפסי הלידים העמוד לא שויך ל-System User. /meta app, צעד 5 ברשימה שלו, ואז /check
קוד 200, "API access blocked", בכל בדיקה Meta חסמה את חשבון המפתחים של מנהל האפליקציה. זו לא בעיה בטוקן. משלימים את האימות ב-developers.facebook.com בפרופיל האישי (לא בפרופיל העמוד), ואז /meta token
קוד 190 הטוקן שגוי או בוטל. /meta token: קודם Revoke, אחר כך Generate
"the value is empty" אחרי copied ה-Copy לא נקלט בלוח. לוחצים Copy שוב וכותבים copied
הטוקן הופיע בצ'אט הוא שרוף. Revoke ב-Business Settings, ואז /meta token
הכלים של fal חסרים אחרי הכניסה גם הם נטענים רק בסשן שנפתח אחרי הכניסה. סשן חדש, ואז /fal
כלי חסר ההתקנה שלו לא הושלמה. /install ושם הכלי, למשל /install node
